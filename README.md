# Mostly Harmless Econometrics: Slides

LaTeX (Beamer) slides for the *Mostly Harmless Econometrics* reading group at
Washington University in St. Louis.

**Website:** <https://kevin123883.github.io/mostly-harmless-seminar/>
(session pages, compiled slide PDFs, readings, and recordings)

## Layout

```
sessionN/sessionN.tex     main deck for session N
sessionN/sessionN-1.tex   extra decks for session N (e.g. recitations)
drafts/                   notes not yet assigned to a session (not published)
```

Slides are edited in Overleaf and synced to this repository. The
[website repo](https://github.com/Kevin123883/mostly-harmless-seminar) compiles
every `session*/session*.tex` here and publishes the PDFs to the site.
